### 🚀 Najważniejsze Projekty

Projekty, które wymagały najwięcej rygoru inżynieryjnego:

#### 1. [Pulpit Studenta] (w folderze [/Podstawy Aplikacji Internetowych](https://github.com/kamikaj/Studia-rok-2/tree/main/Podstawy%20Aplikacji%20Internetowych/Projekt_ko%C5%84cowy))
*   **Czym jest:** Kompletne środowisko do zarządzania procesami edukacyjnymi, czasem oraz komunikacją.
*   **Czego się nauczyłem:**
    *   **Architektura SPA i Czysty JS:** Budowa zaawansowanej aplikacji typu Single Page Application przy użyciu czystego JavaScriptu (Vanilla JS ES6+) – samodzielne zarządzanie stanem i pełna logika CRUD bez frameworków.
    *   **Asynchroniczność i Trwałość danych:** Praktyczne zastosowanie Fetch API oraz formatu JSON do bezprzeładowaniowego przepływu danych, połączone z ich utrwalaniem w Web Storage (localStorage).
    *   **Bezpieczeństwo i Środowisko:** Zrozumienie mechanizmów przeglądarki, w tym polityki bezpieczeństwa CORS i różnic w protokołach sieciowych (http:// vs file://).
    *   **UI/UX i Dostępność (a11y):** Wdrożenie responsywnego interfejsu (Bootstrap 5) oraz dynamicznego systemu motywów (zmienne CSS), w tym trybu wysokiego kontrastu dla osób z dysfunkcjami wzroku.
*   **Uruchom projekt:** [🚀 Zobacz Live Demo](https://pulpitstudenta.vercel.app/)

#### 2. [System Sklepu Internetowego] (w folderze [/Podstawy Inżynierii Oprogramowania](https://github.com/kamikaj/Studia-rok-2/tree/main/Podstawy%20In%C5%BCynierii%20Oprogramowania))
*   **Czym jest:** Projekt systemu informatycznego dla sklepu internetowego, zaprojektowany w celu optymalizacji procesów sprzedażowych, magazynowych oraz księgowych.
*   **Technologie:**
    *   Notacja BPMN (modelowanie procesów biznesowych).
    *   Diagramy DFD (poziom 1 i 2) oraz ERD (projektowanie bazy danych).
    *   Projektowanie mockupów (UI/UX) dla ról: Sprzedawca, Magazynier, Księgowa.
    *   XML jako format wymiany danych.

#### 3. Interaktywne Projekty Układów Cyfrowych (Platforma CircuitVerse)
* **Czym jest:** Zbiór autorskich, w pełni interaktywnych schematów logicznych zrealizowanych w ramach przedmiotu Podstawy Technik Cyfrowych. 
* **Obszar inżynieryjny:**
    * **Logika kombinacyjna i sekwencyjna:** Projektowanie, analiza i optymalizacja zaawansowanych układów cyfrowych (podstawowe bramki, multipleksery, demultipleksery, przerzutniki i liczniki).
    * **Optymalizacja sprzętowa:** Praktyczne zastosowanie algebry Boole’a oraz map Karnaugha w celu minimalizacji liczby elementów logicznych w strukturze układu.
* **Uruchom symulację:** [🚀 Moje Schematy na CircuitVerse](https://circuitverse.org/users/399397)
